# La Bella Pizza — versão corrigida

Arquivos:
- index.html
- cardapio.html
- entregas.html
- style.css
- script.js

Como testar:
1. Coloque todos os arquivos na mesma pasta.
2. Abra `index.html` no navegador.
3. Para uma experiência melhor com a API ViaCEP, rode por um servidor local (por exemplo, Live Server no VS Code).
4. O carrinho usa localStorage e continua entre index, cardápio e entregas.
5. O acompanhamento do pedido é uma simulação local e avança automaticamente.

Observação:
A versão foi organizada para funcionar como site estático, sem depender de backend. Depois, o Java/Spring Boot pode substituir as partes simuladas de pedido e rastreamento.
